# Термины исследования

## Основные понятия

| Термин | Значение |
| --- | --- |
| Обоснование решения | Почему выбран вариант: требования, предпосылки, рассмотренные альтернативы и основания выбора |
| Инженерное суждение | Вывод на основе инженерных знаний и опыта при неполных данных; основания и неопределённость должны быть явными |
| Выбор по критерию достаточности | Поиск и принятие решения, удовлетворяющего заданному уровню требований. Также используется выражение «выбор удовлетворительного решения» |

«Выбор по критерию достаточности» — поясняющий термин для этого исследования. Связь с идеями Саймона о поиске решения при ограниченной рациональности рассматривается в [плане чтения](05-learning-path.md). Приемлемость определяется явными критериями.

## Проектирование и оценка

| Термин | Значение |
| --- | --- |
| Атрибуты качества | Например, производительность, надёжность и изменяемость |
| Архитектурно значимые требования | Требования, существенно влияющие на архитектурные решения |
| Дерево полезности | В ATAM: иерархия атрибутов качества и сценариев с приоритетами |
| Заинтересованные стороны | Участники, чьи интересы затрагивает система |
| Интересы и вопросы заинтересованных сторон | То, что важно отразить и проверить в архитектуре |
| Архитектурные точки зрения | Правила построения представлений архитектуры для определённых интересов |
| Проектные концепции | Принципы, стили, паттерны и тактики, используемые при проектировании |
| Факторы, определяющие архитектуру | Существенные требования, ограничения и цели проектирования |
| Облегчённая оценка архитектуры | Оценка с сокращённым объёмом процедуры |
| Сокрытие информации | Скрытие проектных решений за границами модулей, чтобы ограничить влияние их изменения |
| Декомпозиция по изменчивости | Выделение границ с учётом того, какие решения и части системы могут изменяться |
| Коварные проблемы | Проблемы со спорной постановкой и критериями оценки, где действия меняют условия задачи. Поясняющий термин для работ Риттеля и Веббера |
| Социотехническая согласованность | Соответствие взаимодействий участников зависимостям выполняемой технической работы |
| Архитектурные фитнес-функции | Проверки соответствия архитектуры заданным целям и ограничениям |

## Рассуждение

| Термин | Значение |
| --- | --- |
| Когнитивное искажение | Систематическое отклонение в рассуждении и оценке |
| Эффект якоря | Чрезмерная зависимость от исходной информации или первого варианта |
| Чрезмерный оптимизм | Переоценка благоприятных исходов или недооценка трудностей |
| Предвзятость подтверждения | Избирательный поиск и трактовка данных в пользу своей позиции |
| Ошибка ретроспективного взгляда | Переоценка предсказуемости исхода после того, как он стал известен |
| p-значение | Вероятность получить результат не менее экстремальный, чем наблюдаемый, при заданной нулевой гипотезе и предпосылках анализа |

## Поведение и реализация

| Термин | Значение |
| --- | --- |
| Проверка модели | Автоматическая проверка заданных свойств поведения модели |
| Свойство безопасности | Требование, что недопустимое состояние или событие никогда не возникает |
| Свойство живости | Требование, что предусмотренное событие или прогресс в итоге наступает при заданных предпосылках |
| Содержимое запроса | Переданные данные, имеющие смысл для операции |
| Фиксация транзакции | Подтверждение и сохранение её изменений |
| Устойчивое сохранение подтверждённых данных | Сохранение зафиксированных изменений после предусмотренных сбоев |
| Аварийное завершение | Прерывание процесса вследствие сбоя |
| Транзакционная таблица исходящих сообщений | Хранение намерения отправить сообщение в той же транзакции, что и изменение данных |
| Накопленная очередь | Задания или сообщения, ожидающие обработки |
| Повторная попытка | Новая попытка выполнить операцию после неуспеха |
| 99-й процентиль времени ответа | Значение, не превышенное в 99% измеренных ответов при выбранном способе расчёта |

Определения задают словарь исследования; при точном разборе метода учитывается смысл термина в первоисточнике.
