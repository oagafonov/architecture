# Журнал целевого поиска при ревью

Дата: 11 октября 2026 года. Цель: проверить минимальный маршрут для исследования правил архитектурной аргументации и найти современный эмпирический материал.

Это **ограниченный целевой поиск**, а не систематический обзор литературы. Использованы Crossref и arXiv, просмотрены верхние ранжированные совпадения по нескольким запросам. Полный обход цитирований, независимый отбор, поиск по всем научным базам и оценка всех найденных текстов не выполнялись.

## Сохранённые данные

- [search-results.json](search-results.json): точные URL запросов Crossref, фильтры, HTTP-статусы, число возвращённых записей и их заголовки/DOI/даты. Числа относятся только к возвращённым страницам; дубликаты сохранены по запросам.
- [verification.json](verification.json): сверенные метаданные L30–L33, адреса прочитанных материалов, объём проверки и SHA-256 полученных файлов.

Полные издательские тексты и PDF не включены в репозиторий. Хеш фиксирует полученный документ; для изменяемой веб-страницы не обещает неизменность будущего ответа. arXiv PDF закреплён на v1.

## Как использованы результаты

| Находка | Решение при ревью | Основание |
| --- | --- | --- |
| SAIP 4 и первичный отчёт ATAM | Обязательные выбранные разделы | Язык критериев и конкретные правила оценки; содержание и границы отчёта проверены |
| Borowa и соавт., Debiasing Architectural Decision-Making, 2025 | L30, обязательный источник | Прямое соответствие архитектурной аргументации, эмпирическое сравнение, доступная авторская версия |
| Tang и соавт., A Survey of Architecture Design Rationale, 2006 | L31, условное расширение | Историческая практика документирования обоснований решений; полный текст не прочитан |
| De Jong и соавт., Evaluating Design Rationale in Architecture, 2019 | L32, кандидат | Название и метаданные релевантны; читаемый текст пока не получен |
| Mori и соавт., Toward Evidence-Based Architectural Decision Making Over Fragmented Knowledge, 2026 | L33, кандидат | Свежая запись непосредственно по теме; выводов о содержании по одному названию не сделано |
| Sahlabadi и соавт., Lightweight Software Architecture Evaluation for Industry: A Comprehensive Review, 2022; DOI 10.3390/s22031252 | Условный кандидат при вопросе о затратах процедур | Метаданные и аннотация Crossref просмотрены; полный текст не получен |
| Результаты о строительстве, нейросетях, специальных видах систем или генерации обоснований решений с помощью больших языковых моделей | Не добавлены в обязательный маршрут | По заголовкам не дают необходимого нового шага для текущего вопроса; полные тексты не оценивались |

## Проверки доступа

| Запрос | Результат и интерпретация |
| --- | --- |
| SEI: страница ATAM и официальный PDF | HTTP 200, читаемые материалы |
| InformIT: SAIP 4 | HTTP 200, сведения и оглавление; полный текст книги не получен |
| Crossref | Восемь успешных запросов; один запрос по рассуждениям при проектировании вернул HTTP 429 и не использован. Crossref ранжирует совпадения, а не выполняет строгий логический отбор |
| arXiv: поиск Debiasing Architectural Decision-Making | Возвращены 13 результатов; найден подходящий текст с авторами Borowa, de Almeida, Wiese. Другие совпадения не стали источниками выводов |
| arXiv: 2502.04011 и PDF v1 | HTTP 200; просмотрены аннотация, методика, результаты, ограничения и выводы |
| arXiv: широкий запрос Evidence-Based Architectural Decision Making | Показаны первые 50 из 104 совпадений; большая часть нерелевантна по заголовку. Поиск не заявляется полным |
| arXiv: точная фраза Evidence-Based Architectural в поле названия | Совпадений нет. Это не доказывает отсутствия L33 или её доступной авторской версии где-либо ещё |
| IEEE: страница L32 и переход через DOI | HTTP 202 без читаемого текста; не засчитано как чтение |
| Официальный портал UU для L32 | CONNECT HTTP 403; содержание не получено |
| MDPI для обзора облегчённой оценки архитектуры | CONNECT HTTP 403; аннотация Crossref не заменяет полный текст |
| PMC: ранее предоставленная ссылка на гранулярность | HTTP 200 с проверкой браузера; текст статьи не получен |

Первоначальные сетевые отказы из каталога не описывают доступность всех источников во время ревью. Новые результаты подтверждают только проверенные конкретные операции. Из этого поиска не следует ни новизна проблемы, ни исчерпывающее состояние исследований на 2026 год.
