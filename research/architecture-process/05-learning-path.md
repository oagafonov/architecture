# Минимальный план чтения

Цель — найти правила достаточного качества, выявления риска, оценки значимости различий и остановки анализа. Обязательный минимум — три источника. Для каждого важно выяснить, какие основания доступны независимой проверке и что остаётся суждением участников.

## Результат первого этапа

Один короткий документ:

1. **Правила:** достаточность, риск, сравнение, остановка; источник, проверка, оставшееся суждение.
2. **Кейс:** 2–3 альтернативы, 3–5 аргументов, существенные требования и риски, значимость различий, основание завершить либо продолжить анализ.
3. **Свидетельства:** предотвращённые ошибки, свойства систем и затраты процесса; границы вывода и следующий вопрос.

Результат сравнения может быть трёх видов: существенное различие, подтверждённая практическая равноценность или нехватка данных. Для тренировки подходит [учебный пример](04-worked-example.md); для проверки конкретной эвристики — [кейс модульности](08-modularity-and-cost.md).
