# Достаточное качество архитектурных решений

**Как архитектурный процесс устанавливает достаточность решения, выявляет неприемлемые риски и определяет, когда дальнейший поиск лучшего варианта оправдывает затраты?**

Разные архитекторы могут предложить работающие решения одной задачи и спорить о превосходстве. Возможно, во многих случаях основной вклад архитектурного процесса — предотвращение существенно плохого выбора, а различия между приемлемыми вариантами невелики. Это рабочая гипотеза исследования.

Задача — выяснить, какие методы дают проверяемые основания для оценки достаточного качества, существенности различий и остановки поиска. Сравнение альтернатив и проверка аргументов входят в эту задачу.
